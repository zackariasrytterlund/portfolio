# Portfolio – plan

Startad: 2026-11-12 (skoluppgift)

## Beslut
- **Format:** webbsida
- **Design:** Figma
- **Kod:** HTML och CSS (främst), skrivs i VS Code
- **Publicering:** GitHub

## Arbetsflöde
1. Designa i Figma
2. Koda i VS Code (HTML/CSS)
3. Pusha till GitHub och publicera

## Inriktning (besvarat 2026-11-12)
- **Målgrupp:** praktik/jobb. Sidan ska övertyga en arbetsgivare snabbt.
- **Känsla:** lekfull, med mycket rörelse (motion). Rörelsen görs i CSS (transitions/animations).
- **Material:** allt: logotyper/branding, motion/Blender, appar och hemsidor han har byggt.
  Eftersom materialet är brett behövs filter eller kategorier så att det inte blir rörigt.

## Föreslagen sidstruktur (utkast)
1. Hero: namn, en rad om vem Zacke är och en lekfull animation
2. Utvalda projekt: 3–4 starkaste case
3. Alla projekt: rutnät med kategorier (Branding · Motion/3D · Webb/Appar)
4. Om mig: bild, kort text och verktyg
5. Kontakt: mejl, LinkedIn, GitHub och CV
